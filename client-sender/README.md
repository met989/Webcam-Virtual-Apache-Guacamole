# VirtualCam Sender

For the sender computer you can choose between two convenient modes:

---

### Option A: In Browser (Zero Installation)
1. Open Google Chrome or Microsoft Edge.
2. Navigate to: `https://guacamole.reload.local/cam`
3. Click **"Start Webcam"** and minimize the tab.

---

### Option B: Standalone Application Window
If you prefer not to keep open tabs in your standard browser:
1. Double-click **`webcam_sender.exe`** (or `start_webcam.bat`).
2. A clean, standalone native window opens without browser chrome.
3. Click **"Start Webcam"** and minimize to tray.
