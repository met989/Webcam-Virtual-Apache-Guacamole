# Virtual Webcam Driver (DirectShow Filter)

Lightweight DirectShow virtual capture driver (~320 KB).

## Installation on Workstations:

1. Right-click `install_virtual_webcam.bat` and select **"Run as administrator"**.
2. Windows will register the new video capture device:
   **`Virtual Webcam`**

## Removal:
1. Right-click `uninstall_virtual_webcam.bat` and run as administrator.
